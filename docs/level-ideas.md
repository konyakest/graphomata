# 关卡点子库（图灵完备向）

> 前提：这套机器是图灵完备的——可增长的图 + 循环 + 节点身份比较，等价于一个堆无限的指针机。
> 所以题目可以出得很难：**难在算法，不难在语法**。
>
> 下面按「能直接做」到「需要先升级判题器」排序。标 ✅ 的是我已经用现有引擎跑过参考解的。

---

## 0. 先记住四条限制

### 0.1 `next()` 在出度 > 1 时是随机的

这是关卡设计的头号约束。**遍历用的骨架必须保持出度 1**：

- 沿着链/环走的时候，不要给当前节点加第二条出边；
- 必须先 `nxt = p.next()` 把下一条边读出来，再 `p.link(...)`；
- 加稠密边（完全图、树的分支遍历）会毁掉后续的 `next()`，所以这类题基本不能出。

### 0.2 GC 是沿出边的有向可达

- 返回节点所在的分量活下来，其它整块回收；
- 想保留输入图，就必须让某个变量指着它；
- 想丢掉输入图，最简单的方式就是 `return` 之后不再引用它。

### 0.3 判题是形状同构 + `return_new`

- 判不了“你返回的是不是环的入口”这种身份问题，除非形状本身不同；
- 需要“新图”的关卡加 `return_new: true`；
- 判题同构已经升级：**1-WL 颜色细化 + VF2 回溯**，19/25/40 节点的链都在几毫秒内；
  大图关卡（平方链、线程树、指数链）可以直接出（见 §3）。

### 0.4 峰值引用是核心预算

- 难的题通常要 6–8 个引用；
- `max_refs` 要按参考解实测峰值 + 0~1 给，不要凭感觉；
- 引用不够时，玩家必须学会“用完就 `= None`”或把中间状态塞进图里。

## 1. 可以直接做的题

### 1.1 环形复制（Copy a ring）✅ — 困难

- **输入**：n 节点环，起点在环上；
- **目标**：一条新的 n 节点环，`return_new: true`；
- **隐藏**：n = 4 / 6 / 8；
- **核心**：环没有“尾巴”，循环终止条件只能用 `cur is head`；
- **参考解**：

```python
def solve(s):
    out = Node()
    tail = out
    cur = s.next()
    while cur is not s:
        tail.link(Node())
        tail = tail.next()
        cur = cur.next()
    tail.link(out)
    return out
```

- **实测**：n=4 → 16 步；n=6 → 24 步；n=8 → 32 步；峰值 5。
- **为什么难**：第一次要求用节点身份（`is`）而不是 `is None` 终止；还要在正确的时刻收口。
- **考点**：环遍历、身份比较、复制。

### 1.2 链加倍（Double a chain）✅ — 中等

- **输入**：n 节点链；
- **目标**：一条 2n+1 节点的新链，`return_new: true`；
- **隐藏**：n = 3 / 4 / 5；
- **参考解**：

```python
def solve(s):
    out = Node()
    tail = out
    while s is not None:
        tail.link(Node())
        tail = tail.next()
        tail.link(Node())
        tail = tail.next()
        s = s.next()
    return out
```

- **实测**：n=3 → 23 步（7 节点）；n=4 → 30 步（9 节点）；峰值 4。
- **考点**：每个输入节点产生固定数量的输出；输出链增长时 tail 的维护。

### 1.3 隔一个删一个（Thin out）✅ — 中等偏难

- **输入**：2n 节点链；
- **目标**：n 节点链（原地删，不新建节点）；
- **隐藏**：2n = 4 / 6 / 8；
- **核心**：删掉一个节点后必须把前驱重新接到后继，否则链断掉；
- **参考解**：

```python
def solve(s):
    head = s
    p = s
    while p is not None:
        v = p.next()
        if v is None:
            break
        nxt = v.next()
        p.unlink(v)
        if nxt is not None:
            p.link(nxt)
        p = nxt
    return head
```

- **实测**：n=2 → 11 步；n=3 → 16 步；n=4 → 21 步；峰值 6。
- **为什么难**：`unlink` 之外还要 `link` 补边；否则剩下的不是一条链。
- **考点**：改边、前瞻、GC（被删节点在变量改写后被回收）。

### 1.4 双向环（Doubly linked ring）✅ — 困难

- **输入**：n 节点环；
- **目标**：每个节点同时指向后继和前驱（2n 条边）；
- **隐藏**：n = 4 / 6；
- **参考解**：

```python
def solve(s):
    head = s
    prev = s
    cur = s.next()
    while cur is not head:
        nxt = cur.next()
        cur.link(prev)
        prev = cur
        cur = nxt
    cur.link(prev)
    return head
```

- **实测**：n=4 → 16 步；n=6 → 24 步；峰值 6。
- **为什么难**：回边会污染 `next()`，必须先把 `nxt` 读出来再连回边；最后还要补上 head 的回边。
- **考点**：双向指针、环、边污染。

## 2. 高难题（需要更强的判题或更多引用）

### 2.1 环入口复制（Rho copy）✅ — 挑战

- **输入**：一个“棒棒糖”图：长度 t 的尾巴接进长度 r 的环；
- **目标**：复制出一个同样形状（t、r 相同）的新 rho，`return_new: true`；
- **隐藏**：(t, r) = (2,3) / (3,4) / (2,5)；
- **核心**：不能一边走一边复制到死——必须先找到环入口；
- **算法**：
  1. Floyd 判环：`slow` 走一步、`fast` 走两步，相遇；
  2. 从 `s` 和相遇点同时走一步，相遇处就是入口 `entry`；
  3. 复制尾巴 `s → ... → entry` 的前驱；
  4. 从 `entry` 开始复制整个环，最后收口；
  5. `return` 新头。
- **参考解骨架**：

```python
def solve(s):
    slow = s
    fast = s
    while fast is not None and fast.next() is not None:
        slow = slow.next()
        fast = fast.next().next()
        if slow is fast:
            break
    a = s
    b = slow
    while a is not b:
        a = a.next()
        b = b.next()
    entry = a
    # 复制尾巴 + 环（略）
    return out
```

- **为什么难**：Floyd 判环 + 入口定位 + 复制，三层组合；引用也紧张（要做引用复用）。
- **判题**：rho 形状能区分 t 和 r，所以形状同构就够；节点数 ≤ 9 时现有判题器还能跑。

### 2.2 链表平方（Square a chain）— 困难

- **输入**：n 节点链；
- **目标**：一条 1 + 2n² 节点的新链，`return_new: true`；
- **隐藏**：n = 2 / 3；
- **核心**：外层遍历输入，内层再从输入头走一遍，每次追两个输出节点；
- **参考解**：

```python
def solve(s):
    head = s
    out = Node()
    tail = out
    outer = s
    while outer is not None:
        inner = head
        while inner is not None:
            tail.link(Node())
            tail = tail.next()
            tail.link(Node())
            tail = tail.next()
            inner = inner.next()
        outer = outer.next()
    return out
```

- **为什么难**：嵌套循环 + 输入头必须一直活着（否则内层走不了）。
- **判题**：n=3 时输出 19 节点，新判题器直接支持。

### 2.3 线程化二叉树（Threaded tree）— 挑战

- **输入**：单个根节点；
- **目标**：深度 d 的满二叉树 + 每一层节点按顺序串成链表（线程化）；
- **隐藏**：d = 2 / 3；
- **算法**：
  - 维护当前层的 frontier 链（头/尾）；
  - 对 frontier 里每个节点：新建两个孩子、连父子边、把孩子接到下一层的 frontier 链上；
  - 遍历 frontier 时**先读 next 再连孩子**，否则 `next()` 会被孩子污染；
- **为什么难**：同时维护两层链、父子边、线程边；引用约 7–9 个。
- **判题**：d=3 时 15 节点，新判题器直接支持。

### 2.4 指数链（Exponential chain）— 挑战/变态

- **输入**：n 节点链；
- **目标**：一条 2ⁿ 节点的链，`return_new: true`；
- **隐藏**：n = 3 / 4；
- **算法**：重复 n 次“把当前输出链整体复制一份接在后面”：
  - 记住当前链的旧尾巴；
  - 从链头走到旧尾巴，每走一个节点就在尾部追加一个副本；
  - 追加的副本不能再被遍历（用旧尾巴作为边界）。
- **为什么难**：O(2ⁿ) 的节点增长；遍历和追加共用一条链，边界必须精确。
- **判题**：n=4 时 16 节点，新判题器支持；另外要加节点上限。

### 2.5 图灵纸带（Turing tape）— 变态

- **输入**：一条纸带（节点链），用“边到标记节点”表示符号；
- **目标**：模拟一个固定的小型图灵机 k 步，输出纸带形状；
- **为什么难**：要处理读写头、状态、左右移动、停机；
- 这题不是“写一个算法”，是“写一个解释器”，适合作为最终关。
- **前置**：需要先定义纸带编码（用节点/边怎么表示 0/1、空白、读写头），并把判题扩展成“形状 + 指定节点属性”。

## 3. 同构判题（已完成）

`checkGoal` 不再做全排列，改成：

1. 把两张图放到**同一个细化过程**里，按 `(入度, 出度)` 初始化颜色，再用邻居颜色迭代细化（1-WL）；
2. 颜色直方图不同 → 直接判否；
3. 颜色类里用 **VF2 式回溯**：优先选候选最少节点，已映射的邻居做双向边一致性剪枝；
4. 链、环、树这类图，颜色细化后基本是“确定一个头，然后沿边唯一映射”，线性；对称图才进回溯。

实测：19/25/40 节点的链重排后判同构分别是 1.9 / 1.5 / 4.5 ms；“两个三角形 vs 一个六边形”正确判否。
代码在 `web/ptr/world.js` 的 `isomorphic()`。
